# HoldMyTask v2.0.3 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

v2.0.3 moves the development toolchain to vitest 5, brings the CI workflows up to the current CLDMV v4 templates, and adopts uniform file headers and the verbatim Apache-2.0 license text. No runtime code changed: the only edits under `src/`, `index.mjs`, `index.cjs`, `devcheck.mjs` and `build.mjs` are header comments.

---

## 🔧 CI & tooling

### v4 workflow sync ([#34](https://github.com/CLDMV/holdmytask/pull/34), [#35](https://github.com/CLDMV/holdmytask/pull/35), [#39](https://github.com/CLDMV/holdmytask/pull/39), [#40](https://github.com/CLDMV/holdmytask/pull/40))

The workflows were synced with the `CLDMV/.github` v4.29 templates. New workflows are `bundle-size`, `release-merge`, `provenance`, `pr-notify`, `member-auto-merge` and `dependabot-recreate`. The bundle-size job no longer double-counts files, and the in-repo "Required PR Check" mirror job now runs instead of being skipped, so a skipped run can no longer satisfy the required check.

### Dependabot grouping

`.github/dependabot.yml` gained `vitest`, `eslint` and `prettier` groups. `@vitest/coverage-v8` pins an exact `vitest` peer, so a partial bump fails `npm ci`; grouping the family keeps the versions in step.

### File headers ([#38](https://github.com/CLDMV/holdmytask/pull/38))

The shared `@cldmv/fix-headers` configuration was adopted (`npm run fix:headers`), and uniform headers were stamped on the source, test and example files. Only comments changed.

## 📚 Documentation

- The `LICENSE` file was restored to the verbatim Apache-2.0 text ([#33](https://github.com/CLDMV/holdmytask/pull/33)).

## 🔧 Dependencies

All development dependencies:

- `vitest`, `@vitest/coverage-v8` and `@vitest/ui` 4.1 → 5.0 ([#29](https://github.com/CLDMV/holdmytask/pull/29)); the three are bumped together because their peer ranges are exact.
- The minor group ([#37](https://github.com/CLDMV/holdmytask/pull/37)): `eslint` 10.9.1 → 10.11.0, `@eslint/json` 2.0.1 → 2.1.0, `@html-eslint/*` 0.65 → 0.66, and `@cldmv/vitest-runner` 1.2.0 → 1.5.1 in the lockfile.
- `@types/node` 26.4.0 → 26.4.1 ([#27](https://github.com/CLDMV/holdmytask/pull/27)).
- `@cldmv/fix-headers` and `@cldmv/configs` were added.
