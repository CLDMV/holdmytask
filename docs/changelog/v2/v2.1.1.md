# HoldMyTask v2.1.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/2.1.1`

---

## Overview

v2.1.1 sets `engines.node` back to the Node.js version the package needs at runtime, `>=18.12.0`, instead of the 22.22.0 development toolchain floor that v2.1.0 put there. The 22.22.0 floor moves to npm's `devEngines`, which only applies when you work on this repository.

The queue, its options and the exports are the same as in v2.1.0. Installs on Node.js 18.12 through 22.21 no longer get an `EBADENGINE` warning.

---

## 🐛 Bug Fixes

### `engines.node` is the runtime floor again ([#94](https://github.com/CLDMV/holdmytask/pull/94))

v2.1.0 raised `engines.node` from `>=18.12` to `>=22.22.0` because the development toolchain (tsup 9 among others) doesn't run on earlier 22.x releases. The published package doesn't need any of that toolchain, so the floor was stricter than the code. `engines.node` is `>=18.12.0` again, and the bundles are built for `node18` (tsup `target`, was `node20`).

`import` works on Node.js 18.12.0 and later. `require("@cldmv/holdmytask")` loads the ES module build synchronously, which needs `require(esm)`: Node.js ^20.19.0 or >=22.13.0. On a Node.js without it, the CommonJS entry now says exactly that (`require() needs Node.js ^20.19.0 or >=22.13.0`, code `ERR_REQUIRE_ESM`) and points to `import()`; v2.1.0's message asked for 22.22.0.

## 📦 Requirements

- **Runtime:** Node.js 18.12.0 or later for `import` (`engines.node` is `>=18.12.0`, was `>=22.22.0`). `require()` needs Node.js ^20.19.0 or >=22.13.0; use `import()` on older versions.
- **Development:** working on this repository needs Node.js 22.22.0 or later, declared in `devEngines.runtime` with `onFail: "error"`. This doesn't affect anyone installing the package.

## 🔧 CI & tooling

- The CI and publish workflows keep `min_node_version` at 22.22.0; its description and a comment now say it's the dev toolchain floor and should match `devEngines`, not `engines` ([#94](https://github.com/CLDMV/holdmytask/pull/94), [#96](https://github.com/CLDMV/holdmytask/pull/96)).

## Upgrade notes

- No breaking changes; drop-in for v2.1.0. Apart from the CommonJS entry's error message and the `node18` build target, no library code changed.
