**Release Date**: September 2026
**Release Type**: Patch

## Overview

v2.0.1 fixes a task-timeout cleanup bug and updates development dependencies.

---

## 🐛 Bug Fixes

### Task timeout timer is cleared when a task fails or is cancelled

When a task has a `timeout`, the task runner starts a timer for it. A second `let timeoutId` declaration inside the `try` block shadowed the outer variable, so the cleanup in the `finally` block read the outer one, which was never assigned. A task that succeeded cleared its timer on the normal path, but a task that threw or was cancelled left the timer armed until the timeout elapsed. The duplicate declaration was removed, so the timer is now cleared on every path.
