# HoldMyTask v2.0.4 Changelog

**Release Date**: October 2026
**Release Type**: Patch
**Branch**: `next`

---

## Overview

v2.0.4 is a dependency-only patch on top of [v2.0.3](https://github.com/CLDMV/holdmytask/releases/tag/v2.0.3). It picks up a fix for a medium-severity denial-of-service advisory in `brace-expansion`, a development-time transitive dependency, and moves two development tools forward.

No runtime code changed: nothing under `src/`, `index.mjs`, `index.cjs` or `devcheck.mjs` is touched, and the published bundle is byte-for-byte the same size as v2.0.3. Consumers of the package are unaffected.

---

## 🔒 Security & supply chain

### brace-expansion 5.0.9 → 5.0.12 ([#44](https://github.com/CLDMV/holdmytask/pull/44))

Fixes [GHSA-q2hr-2g5m-vwhr](https://github.com/advisories/GHSA-q2hr-2g5m-vwhr) (CVE-2026-102277, medium, CVSS 5.3): expanding `{a},b}`-shaped input took quadratic time in the number of literal `}` characters, so an untrusted pattern could block the event loop. `brace-expansion` is a development-only dependency, pulled in solely by `minimatch` in the lint and test toolchain, and the package has no runtime dependencies, so the shipped code never loaded it. The update clears the open Dependabot alert on the lockfile.

## 🔧 Dependencies

- `@eslint/css` 1.4.0 → 2.0.0 (development; [#43](https://github.com/CLDMV/holdmytask/pull/43)). The major release adds `meta.languages` to the CSS rules. `npm run lint` passes unchanged with the repo's `css/recommended` configuration.
- `prettier` 3.9.6 → 3.9.9 (development; [#41](https://github.com/CLDMV/holdmytask/pull/41)). Lockfile-only: the `^3.0.0` range in `package.json` already allowed it.

## 🔧 CI & tooling

- The header comments in the generated `types/*.d.mts` files and their source maps were refreshed to the shared file-header format. Only comments changed; no type declarations differ from v2.0.3.

No breaking changes — drop-in for v2.0.3. No runtime code changed.
