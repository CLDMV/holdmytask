# HoldMyTask v2.0.6 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

v2.0.6 is a development-dependency release: `eslint` moves to 10.12.0, `globals` to 17.13.0, `@cldmv/vitest-runner` to 1.5.3 and `@types/node` to 26.6.4. The test runner now declares Node.js 22.12 as its minimum and brings `chalk` 6 with it.

The published package is unchanged. The net diff against v2.0.5 is the lockfile and the `version` field of `package.json`, no source, type declaration or declared range was edited, and the package has no runtime dependencies. Every package that moved is a development dependency or a transitive of one. The automated lint and format commit that closed out the `next` branch ([2c6cdec](https://github.com/CLDMV/holdmytask/commit/2c6cdece391e2ff3fd389b7fe0fc9e51383d55d8)) rewrote 23 generated `types/` files, and the result is byte-identical to the declarations shipped in v2.0.5, so `types/` has no net change.

---

## 🔧 Dependencies

All updates are development-only and lockfile-only: the ranges in `package.json` already allowed the new versions.

- `eslint` 10.11.0 → 10.12.0 ([#64](https://github.com/CLDMV/holdmytask/pull/64)).
- `globals` 17.12.0 → 17.13.0 ([#66](https://github.com/CLDMV/holdmytask/pull/66)).
- `@cldmv/vitest-runner` 1.5.1 → 1.5.3 ([#65](https://github.com/CLDMV/holdmytask/pull/65)). Version 1.5.3 makes the runner's CommonJS entry fail with a clear error on a Node.js version without `require(esm)` and raises its `engines.node` from `>=20.19.0` to `>=22.12.0`. The locked package's license field also changes from MIT to Apache-2.0. Its `chalk` dependency moves from `^5.4.1` to `^6.0.1`: the nested `chalk` 5.6.2 copy is gone and a single top-level `chalk` 6.0.1 takes its place, whose `engines` changes from `^12.17.0 || ^14.13 || >=16.0.0` to `>=22`. `chalk` is reached only through the test runner.
- `@types/node` 26.6.3 → 26.6.4 ([#65](https://github.com/CLDMV/holdmytask/pull/65)).

### Node.js floors

The package's own `engines.node` stays `>=18.12`, and that range describes who can install and run HoldMyTask; none of the updated packages is part of the published files. The development toolchain already needed Node.js 22.12 (`vitest` 5, `@cldmv/fix-headers`) and the CI matrix starts at 22.12.0, so CI and contributors are unaffected; `@cldmv/vitest-runner` now declares the same floor.
