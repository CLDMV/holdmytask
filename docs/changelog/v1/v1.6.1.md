# HoldMyTask v1.6.1 Changelog

**Release Date**: November 2025
**Release Type**: Patch

---

## Overview

This release reworks the package entry point (`index.mjs`) so the development-environment check runs before the library is loaded, and fixes a misleading message in that check.

---

## 💥 Breaking Changes

### The package entry now exports async factories instead of the class

In `index.mjs` the default export is now an async function, `createHoldMyTask(options)`, that dynamically imports `@cldmv/holdmytask/main` and resolves to a new `HoldMyTask` instance. The named exports `createQueue`, `createTaskManager` and `createTaskProcessor` work the same way, and `HoldMyTask`, `queue`, `Queue`, `TaskManager`, `TaskQueue`, `QueueManager` and `TaskProcessor` are now aliases of these factories rather than of the `HoldMyTask` class. The previous `export *` re-export from `@cldmv/holdmytask/main` was removed. `index.cjs` still reads `HoldMyTask` from `index.mjs`, so it receives the factory as well. Code that did `new HoldMyTask(options)` or `new Queue(options)` against the package entry must now `await` the factory instead; the class itself is still available from the `@cldmv/holdmytask/main` subpath export.

```javascript
import createHoldMyTask, { createQueue } from "@cldmv/holdmytask";

const queue = await createHoldMyTask({ concurrency: 5 });
const other = await createQueue({ concurrency: 3 });
```

---

## 🐛 Bug Fixes

The error message printed by `devcheck.mjs` when the development environment is not configured said the setup makes "slothlet" load from `src/`; it now refers to "this module". The development check in `index.mjs` is also imported by relative path (`./devcheck.mjs`) instead of the package specifier.

---

## Upgrade notes

Despite being a patch version, this release changes what the package entry exports. If you construct the queue with `new HoldMyTask(...)` (or one of the aliases) from `@cldmv/holdmytask`, switch to `await createHoldMyTask(...)` (or the matching `create*` function), or import the class from `@cldmv/holdmytask/main`. Everything else is unchanged.
