# HoldMyTask v1.2.0 Changelog

**Release Date**: November 2025
**Release Type**: Minor

---

## Overview

This release adds task coalescing: multiple tasks that share a `coalescingKey` are merged so that only one of them actually runs, cutting down redundant work such as repeated status checks or UI updates.

---

## ✨ Features

### Task coalescing

Tasks enqueued with the same `coalescingKey` inside a time window are grouped, and a single representative task runs the most recently enqueued task function for the whole group. Several groups can exist for the same key over time, since a new group starts once the previous window has closed. Each group's deadline is capped by a maximum delay, so a steady stream of new tasks cannot postpone execution indefinitely.

### Coalescing options

Coalescing is tuned with the constructor options `coalescingWindowDuration`, `coalescingMaxDelay`, `coalescingMultipleCallbacks`, and `coalescingResolveAllPromises`, and each of them can be overridden per task. By default every promise in a group resolves with the shared result; with `coalescingResolveAllPromises: false`, only the latest task resolves and the others are rejected with "Task was coalesced with a newer task". With `coalescingMultipleCallbacks: true`, every callback in the group is called instead of only the latest one. Cancelling a coalesced task removes it from its group, and the group is dropped when it becomes empty.

### `start` option and non-expiring tasks

A new `start` task option schedules a task to become ready a number of milliseconds from now, as a convenience over computing an absolute `timestamp`. Passing `expire: -1` means a task never expires, which is useful together with coalescing.

## 📚 Documentation

- The README gains a Task Coalescing section, including the "fire-and-forget with embedded updates" pattern (enqueue follow-up update tasks from inside the main task, after it finishes, so they always see the final state) and device-control examples.
- New example and stress-test scripts were added under `examples/`, and the obsolete `ROAMAP.md` was removed.

---

## 🔧 Dependencies

- Dev dependencies `vitest` and `@vitest/ui` were bumped from `^1.0.0` to `^4.0.8`.

---

## Upgrade notes

No breaking changes — drop-in for the previous version. Coalescing only applies to tasks that pass a `coalescingKey`.
