# HoldMyTask v1.3.1 Changelog

**Release Date**: November 2025
**Release Type**: Patch

---

## Overview

This patch release fixes two bugs in task bookkeeping: `size()` and `length()` never decreased as tasks finished, and the Promise returned by `enqueue()` lost its task-handle properties after the task completed.

---

## 🐛 Bug Fixes

- `size()` and `length()` now go down as tasks complete, fail, or are cancelled. Completed tasks were previously never removed from the queue's internal task map, so the count only ever grew.
- The Promise returned by `enqueue()` now keeps `result`, `error`, `startedAt`, `finishedAt`, and `status()` available after the task has finished and been removed from the queue.
- Test suite: cancellation tests that created unhandled rejections now handle them, so the 171 tests run without unhandled-rejection warnings.

---

## Upgrade notes

No breaking changes — drop-in for the previous version.
