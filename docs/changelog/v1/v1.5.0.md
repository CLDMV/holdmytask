# HoldMyTask v1.5.0 Changelog

**Release Date**: November 2025
**Release Type**: Minor

---

## Overview

This release adds a set of inspection methods for debugging and monitoring a queue: `inspect()`, `inspectTasks()`, `inspectScheduler()`, `inspectTimers()` and `debugLog()`.

---

## ✨ Features

### Queue inspection methods

`inspect()` returns a full snapshot of the queue: scheduler state, timer state, the pending, ready and running tasks with their counts, totals, coalescing groups and any active completion delay. `inspectTasks()` lists pending, ready and running tasks and breaks them down by priority and by coalescing key. `inspectScheduler()` reports concurrency and available slots, timer ids, the next task to run (including whether it can run now), active delays and queue counts. `inspectTimers()` reports whether the scheduler interval and timeout are active and when the next run is scheduled.

### `debugLog()` console output

`debugLog(detailed = false)` prints a formatted summary of the queue to the console: active or paused status, smart scheduling, concurrency, task counts, timer state, active delays and coalescing groups. Passing `true` adds the individual pending, ready and running tasks.

```javascript
queue.debugLog(); // Basic summary
queue.debugLog(true); // Detailed task information
```
