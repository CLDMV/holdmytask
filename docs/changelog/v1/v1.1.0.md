# HoldMyTask v1.1.0 Changelog

**Release Date**: November 2025
**Release Type**: Minor

---

## Overview

This release replaces constant interval polling with smart scheduling by default: the scheduler now sleeps until the next task is actually due instead of waking on a fixed tick.

---

## ✨ Features

### Smart scheduling

A new `smartScheduling` option (default `true`) makes the queue compute when the next task becomes ready, or when an active delay ends, and set a single timeout for that moment. This removes the constant polling overhead of the previous behavior; the README cites a 31x performance improvement in typical scenarios. A self-healing check, controlled by the new `healingInterval` option (default 5000 ms), restarts the scheduler if work is waiting and it has stalled.

The previous behavior is still available: set `smartScheduling: false` and the queue polls every `tick` milliseconds (default 25) as before.

---

## 🐛 Bug Fixes

- A task's `AbortSignal` is now honored for both the callback and the Promise API; previously only callback-based tasks were cancelled by the queue when their signal aborted. Aborted tasks are cancelled with the message "Task was aborted".

---

## Upgrade notes

No breaking changes — drop-in for the previous version. New queues use smart scheduling automatically; pass `smartScheduling: false` to keep fixed-interval polling.
